# Citlyze for Claude Desktop

This desktop extension connects Claude Desktop to your [Citlyze](https://www.citlyze.com) workspace. It bundles a small local bridge that forwards requests to the hosted Citlyze MCP server at `https://app.citlyze.com/api/mcp` using your workspace API key.

## Setup

1. Create an API key at [app.citlyze.com/workspace-settings](https://app.citlyze.com/workspace-settings) (requires a plan with API access).
2. Install the extension and paste the key when prompted.
3. Ask Claude about your AI search visibility: "How visible is my brand in AI answers this month?", "Which domains get cited for my tracked prompts?", "What should I fix first?"

All nine tools are read-only. See the [tools reference](https://www.citlyze.com/docs/mcp/tools-reference) for details.

## Privacy Policy

This extension sends your requests, along with the API key you configure, to the Citlyze API over HTTPS. It reads workspace data only: it cannot modify anything in your account. No data is collected, stored, or shared by the extension itself beyond forwarding requests to Citlyze.
